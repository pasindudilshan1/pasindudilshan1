[![GitHub Stars](https://img.shields.io/github/stars/pasindudilshan1/dcvpg?style=for-the-badge&color=FFD700&logo=github)](https://github.com/pasindudilshan1/dcvpg/stargazers)

[![GitHub Issues](https://img.shields.io/github/issues/pasindudilshan1/dcvpg?style=for-the-badge&color=FF6B6B&logo=github)](https://github.com/pasindudilshan1/dcvpg/issues)
[![License](https://img.shields.io/github/license/pasindudilshan1/dcvpg?style=for-the-badge&color=03EF62)](https://github.com/pasindudilshan1/dcvpg/blob/main/LICENSE)

> **Catch schema drift, quality violations, and freshness SLA breaches before they reach production.**

</div>

| Feature | What it does |
|---|---|
| 🔍 **Schema Drift Detection** | Catches column additions, drops & type changes automatically |
| ✅ **Data Quality Validation** | Asserts nullability, ranges, regex patterns & referential rules |
| ⏰ **Freshness SLA Monitoring** | Alerts when pipeline data goes stale beyond defined thresholds |
| 🚦 **Pipeline Gate Integration** | Blocks bad data at the source, before it poisons downstream |
| 📋 **Data Contract as Code** | Define and version your data contracts in YAML/JSON |

## 🌟 Featured Project: Restaurant Analytics on Databricks

<div align="center">

### 🍽️ [End-to-End Restaurant Analytics Platform on Databricks](https://github.com/pasindudilshan1/restaurant-analytics-databricks)

[![Databricks](https://img.shields.io/badge/Built_on-Databricks-FF3621?style=for-the-badge&logo=databricks&logoColor=white)](https://github.com/pasindudilshan1/restaurant-analytics-databricks)
[![Azure](https://img.shields.io/badge/Azure-Event_Hub_+_SQL_DB-0078D4?style=for-the-badge&logo=microsoft-azure&logoColor=white)](https://github.com/pasindudilshan1/restaurant-analytics-databricks)
[![Delta Lake](https://img.shields.io/badge/Delta_Lake-Medallion-00ADD4?style=for-the-badge&logo=delta&logoColor=white)](https://github.com/pasindudilshan1/restaurant-analytics-databricks)

> **A complete, production-style Data + AI + BI platform built entirely inside the Databricks Data Intelligence Platform.**

</div>

Models a restaurant chain with **5 UAE locations**, **500 customers**, **~8,000 historical orders**, live streaming orders and thousands of reviews. Ingestion, transformation, AI sentiment analysis, orchestration and dashboards all on **one platform**.

| Capability | Implementation |
|---|---|
| 📥 **Real-Time Ingestion** | Azure Event Hub (Kafka surface) streaming via Spark Declarative Pipelines |
| 🔄 **CDC Batch Ingestion** | Lakeflow Connect from Azure SQL Database with change data capture |
| 🏗️ **Medallion Architecture** | Landing → Bronze → Silver → Gold on Unity Catalog & Delta Lake |
| ⭐ **Star Schema Modeling** | 3 fact tables + 3 dimension tables with data-quality expectations |
| 🤖 **AI in SQL** | Mosaic AI `ai_query()` for review sentiment & issue categorization |
| ⚙️ **Orchestration** | Databricks Workflows: daily master job chaining all pipelines |
| 📊 **AI/BI Dashboards** | Chain Performance & Review Insights dashboards, no external BI tool |
